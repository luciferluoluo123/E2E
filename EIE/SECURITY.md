# Security Policy

## Supported Versions

Security review currently focuses on the `main` branch.

## Security Scope

Security review focuses on:

* Data Validation
* Rule Validation
* Configuration Consistency
* Dependency Security
* Risk Evaluation Components

## Reporting Issues

Please report security-related concerns through GitHub Issues.

When reporting, include:

* A clear description of the issue.
* Affected files or modules.
* Reproduction steps when available.
* Expected and actual behavior.
* Any relevant logs, test output, or configuration context.

Please avoid sharing sensitive data in public issue text.
