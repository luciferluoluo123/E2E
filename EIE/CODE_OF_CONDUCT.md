# Code of Conduct

## Principles

E2E contributors are expected to support a professional and welcoming project environment.

We value:

* Respect
* Collaboration
* Constructive Feedback
* Inclusion

## Expected Behavior

* Communicate clearly and respectfully.
* Focus feedback on ideas, code, and documentation.
* Assume good intent while still addressing issues directly.
* Welcome contributors with different levels of experience.

## Unacceptable Behavior

* Harassment or personal attacks.
* Discriminatory language or conduct.
* Repeatedly disruptive behavior.
* Publishing private information without permission.

## Enforcement

Project maintainers may moderate issues, pull requests, comments, or participation when conduct does not align with this policy.
